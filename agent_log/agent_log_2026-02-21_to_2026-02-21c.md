## 2026-02-21 — Fix: Mobile collapse button hidden when sidebar minimized

**File:** `app/assets/stylesheets/layout.sass`

**Problem:** The `.collapseSidebar` button inside `aside#sidebar` was invisible and unclickable on mobile when the sidebar was minimized, because the parent had `opacity: 0` which cannot be overridden by children.

**Changes:**
1. Replaced `opacity: 0` with `visibility: hidden` on minimized mobile sidebar (line 29)
2. Same replacement in the FOUC prevention rule `html.sidebarMinimized body` (line 62)
3. Added `visibility: visible` and `pointer-events: auto` to the minimized collapse button's mobile media query (lines 397-398), allowing it to override the parent's hidden state

**Why:** Unlike `opacity`, `visibility: hidden` can be overridden by descendants using `visibility: visible`, keeping the toggle button accessible.

## 2026-02-21 — Fix: Mobile sidebar button UX (600px glitch, fixed position, centering)

4. Changed all `window.innerWidth < 600` to `<= 600` in sidebar_controller.js (8 occurrences) to match CSS breakpoint

## 2026-02-21 — Fix: Collapse button too large on mobile landscape

**File:** `app/assets/stylesheets/layout.sass`

**Problem:** On mobile landscape view (601-900px wide, short height), the collapseSidebar button scaled up to `--logo-size` (16rem) on graphic header pages, taking up too much vertical space and hiding nav buttons.

**Changes:**
1. Added media query `(max-width: 900px) and (min-width: 601px) and (max-height: 500px)` to `button.collapseSidebar` — forces `height: var(--header-height)` instead of the large logo size
2. Added matching media query to `body:has(header.header-graphic) #logoContainer` — shrinks logo container to header height with minimal padding on landscape mobile

**Why:** Landscape phones hit the "desktop" breakpoint (>600px) but don't have enough vertical space for the tall 16rem logo area. The `max-height: 500px` condition targets landscape orientation without affecting tablets or desktops.
